# Support

EgoFlow Python Client is a pre-1.0 community project maintained on a best-effort basis.

## Where to ask

- Reproducible bugs and feature requests: [GitHub Issues](https://github.com/ego-flow/ego-flow-py/issues)
- Security vulnerabilities: the private process in [SECURITY.md](SECURITY.md)
- Conduct concerns: the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

Search existing Issues first. Include the `ego-flow` version, Python and operating-system versions,
compatible server version, expected behavior, actual behavior, and a minimal reproduction with
redacted logs.

Never post Python/server tokens, private endpoints, repository names, recordings, datasets, cache
contents, or another person's data in a public Issue.

Support covers the documented API against the compatible EgoFlow Server release. Modified forks,
unreleased branches, custom server behavior, and third-party media/ML stack issues receive no
guaranteed support. Maintainers may close requests that cannot be reproduced, lack required
information, or require confidential data. There is no guaranteed response or resolution time.
